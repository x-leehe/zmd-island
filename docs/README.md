# 布局设计画布（人类专用）

纯本地单页设计工具：用拖拽摆放每个插件在「灵动岛」上的元素，先把视觉样式定下来，再照着做插件。

> **工具归人类使用，图纸归人类出品。**
> - 设计工具本身是给人类做设计用的；若**缺功能 / 组件**，AI 可以补全**工具**（`index.html` / `assets/`）。
> - 但**最终设计必须出自人类之手**——`designs/*.json`（以及由它生成的 `assets/js/*-designs.js` 模板）不由 AI 生成、也不由 AI **重设计**；AI 可以 **refine（小修小改）**，例如更新注释文字、补齐缺失的注释、修掉重叠与越界，但不能改变设计意图。
> - 这是**项目倡议**（便于协作对齐），**非硬性限制**；实际执行由开发者自行把握。

## 使用

双击 `index.html` 即可（零依赖、无需服务器、不联网）：打开就是**通用画布**，左侧调色板拖入组件，按**状态**（等待态 / 展开态 / 收缩态 / 自定义）分别排版。

- 顶部工具栏：网格吸附、对齐参考线、缩放、注释开关、重置本状态；
- **载入模板…**（工具栏下拉）：把某个已归档的设计原样载进来——模板来自 `assets/js/*-designs.js`，由 `designs/*.json` 生成；
- **导出 JSON / 导入 JSON**：归档与复用设计；自定义状态（如「唤起态」）随 JSON 一起走，不进模板；设计名用于区分不同插件。

## 目录

| 路径 | 说明 |
|---|---|
| `index.html` | 唯一入口＝通用画布本体（不绑定插件，只关心「状态 → 视觉」） |
| `assets/css` `assets/js` | 画布样式与脚本（`components.js` 组件集、`canvas.js` 引擎） |
| `assets/js/gen-designs.js` | 生成器：`node docs/assets/js/gen-designs.js <json>` → 写出同名 `<page>-designs.js` |
| `assets/js/*-designs.js` | 内置模板数据（**由 JSON 生成，别手改**） |
| `designs/*.json` | 各插件**在做的**设计稿（导出产物，可再导入） |
| `designs/completed/` | 已完成模块的设计稿归档（只作留档，不再改动） |

## 说明

- 与本仓库的**应用构建无关**：不参与 `dotnet build` / 打包，也不随发版分发；纯静态 HTML，直接双击打开即可。
- `designs/*.json` 是**唯一真源**（视觉规格的参考，不是运行时代码）；`assets/js/*-designs.js` 由它生成，两者保持同源——改了 JSON 记得重跑生成器。
