# 布局设计画布（人类专用）

纯本地单页设计工具：用拖拽摆放每个插件在「灵动岛」上的元素，先把视觉样式定下来，再照着做插件。

> **工具归人类使用，图纸归人类出品。**
> - 设计工具本身是给人类做设计用的；若**缺功能 / 组件**，AI 可以补全**工具**（`index.html` / `canvas.html` / `assets/`）。
> - 但**最终导出、归档的 JSON 图纸必须出自人类之手**——`designs/*.json`（以及 `assets/js/*-designs.js` 模板）不要由 AI 生成或改写。
> - 这是**项目倡议**（便于协作对齐），**非硬性限制**；实际执行由开发者自行把握。

## 使用

双击 `index.html` 即可（零依赖、无需服务器、不联网）。进入「布局画布」后：

- 左侧调色板拖入组件；按**状态**（等待态 / 展开态 / 收缩态 / 自定义）分别排版；
- 网格吸附、对齐参考线、缩放、注释等辅助开关在顶部工具栏；
- 「导出 JSON / 导入 JSON」用于归档与复用设计；设计名用于区分不同插件。

## 目录

| 路径 | 说明 |
|---|---|
| `index.html` | 入口（卡片式导航到各插件画布） |
| `canvas.html` | 通用画布本体（不绑定插件，只关心「状态 → 视觉」） |
| `assets/css` `assets/js` | 画布样式与脚本（`components.js` 组件集、`canvas.js` 引擎） |
| `assets/js/*-designs.js` | 内置的模板数据（music / weather / monitor / notify / clipboard / file / settings） |
| `designs/*.json` | 各插件已归档的设计稿（导出产物，可再导入） |

## 说明

- 与本仓库的**应用构建无关**：不参与 `dotnet build` / 打包，也不随发版分发；纯静态 HTML，直接双击打开即可。
- 设计稿（`designs/*.json`）是**视觉规格的参考**，不是运行时代码。
